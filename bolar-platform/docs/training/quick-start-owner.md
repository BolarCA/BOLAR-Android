# Quick start: landlord portal (/owner)

Demo account owner@demo.bolar.test. You see only the properties you own and the leases, documents and money that
belong to them.

## 1. Dashboard (/owner)

Screenshot (described): heading "Portfolio"; KPI cards Properties, Units, Occupancy (percentage), Approvals,
Collected, Overdue, Maintenance; a list of property cards each with an occupancy bar; a map area labelled as coming in
the reporting phase; an "Approvals inbox" with the tenant name, property and unit and a "Review and approve" link.

- Figures are computed from invoices and payments on your properties only.

## 2. Approvals (/owner/approvals)

Screenshot (described): heading "Lease approvals"; a table with tenant, property and unit, rent, status `review` and
an "Approve lease" button per row.

- Approving records you as the second person on the lease; the manager then sends it for signature. You cannot
  approve a lease you drafted yourself.

## 3. Properties (/owner/properties)

Screenshot (described): heading "My properties"; search box; links to each owned property; the detail page lists
units and statuses without edit buttons.

- A property you do not own is never listed and its direct URL shows the denied state.

## 4. Documents (/owner/documents)

Screenshot (described): a documents table with title, category, classification and a download action.

- Confidential documents may require an access request; downloads use short-lived signed links.

## Questions

Use the support path in [../runbooks/support-escalation.md](../runbooks/support-escalation.md); your property
